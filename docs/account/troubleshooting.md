# 账户问题排查

这一页整理充值、余额、订阅和发票相关的常见问题。

## 在线充值不可用

页面可能提示“尚未启用在线充值”。处理方式：

- 使用兑换码。
- 联系管理员确认充值入口是否开放。
- 等待平台恢复支付渠道。

## 支付成功但余额没变

按顺序检查：

1. 刷新 `Wallet` 页面。
2. 查看是否有新钱包流水。
3. 查看订单状态是否成功。
4. 核对支付账号是否和当前登录账号一致。
5. 保存订单号、支付截图、支付时间后联系平台。

## 订阅购买失败

常见原因：

- 余额不足。
- 套餐已下架或暂未开放。
- 优惠码不可用。
- 支付方式不可用。
- 当前账号没有购买权限。

处理方式：

1. 先确认钱包余额。
2. 换一个套餐或支付方式。
3. 不使用优惠码重试。
4. 联系平台确认订阅功能是否对当前账号开放。

## 看不到订阅套餐

可能原因：

- 当前没有可购买套餐。
- 账号未登录或登录状态失效。
- 订阅模块未对当前用户开放。
- 页面数据加载失败。

建议刷新页面，重新登录后再试。如果仍然看不到，以平台控制台显示为准。

## 余额消耗过快

排查方向：

- 到 `Usage Logs` 查看消耗最高的模型。
- 检查是否使用了高倍率模型。
- 检查是否有代码工具持续调用。
- 给测试 API Key 设置额度限制。
- 减少长上下文请求和最大输出长度。

## 发票无法申请

可能原因：

- 订单未支付成功。
- 当前订单不支持开票。
- 发票中心未开放。
- 发票信息不完整。

处理方式是先确认订单状态，再联系平台处理。
