# 订单与发票

DouDi.ai 的个人中心包含 `Invoice Center`。公开前端文案显示，充值和订阅支付确认时可能展示发票选项，具体是否可开票取决于后台配置和当前订单类型。

## 查看订单

充值或订阅后，建议保留这些信息：

| 信息 | 用途 |
| --- | --- |
| 订单号 | 联系支持或核对支付时使用。 |
| 支付方式 | 判断支付渠道和到账路径。 |
| 实际支付金额 | 核对银行、支付宝、微信或 Stripe 账单。 |
| 到账额度 | 核对钱包是否正确增加。 |
| 余额变更 | 判断充值或订阅扣费是否正确。 |
| 订单状态 | 判断是否支付成功、过期或失败。 |

## 发票中心

进入 `Invoice Center` 后，可以查看付费订单相关的发票记录。公开前端配置中出现了个人、企业、普通票种和发票费用规则等能力，但实际可选项以控制台页面为准。

## 申请发票前确认

- 订单是否已经支付成功。
- 发票类型是否支持个人或企业。
- 发票金额是否和订单金额一致。
- 是否需要填写抬头、税号、邮箱或备注。
- 是否存在开票手续费或最低金额。

## 出现问题怎么办

如果支付成功但没有到账：

1. 到 `Wallet` 刷新余额。
2. 查看钱包流水和订单状态。
3. 保留订单号、支付截图和支付时间。
4. 联系平台管理员或客服处理。

如果发票页面没有记录：

1. 确认该订单是否支持开票。
2. 确认发票中心模块是否对当前账号开放。
3. 联系平台确认是否需要人工开票。
