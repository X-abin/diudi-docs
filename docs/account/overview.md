# 账户概览

DouDi.ai 的账户中心围绕余额、订阅、发票和个人资料展开。根据公开站点状态和前端模块信息，当前个人中心包含 `Wallet`、`Invoice Center`、`Affiliate Commission`、`Profile` 等入口；订阅管理相关能力也存在于站点模块中。

## 常用入口

| 功能 | 入口 | 用途 |
| --- | --- | --- |
| 钱包余额 | `Wallet` | 查看余额、充值、钱包流水和支付结果。 |
| 我的订阅 | `My Subscriptions` | 查看已购买订阅、有效期、套餐权益和订阅记录。 |
| 发票中心 | `Invoice Center` | 查看付费订单关联的发票信息。 |
| 个人资料 | `Profile` | 管理个人资料、安全设置和账号信息。 |
| 调用日志 | `Usage Logs` | 核对 API 调用产生的消耗。 |

## 余额与订阅的关系

DouDi.ai 支持钱包余额体系。公开前端文案显示，订阅可以通过余额购买，且可能支持订阅优惠码。也就是说你可以先充值到钱包，再用余额购买订阅套餐。

常见流程是：

1. 登录 DouDi.ai。
2. 到 `Wallet` 充值余额。
3. 到 `My Subscriptions` 或订阅入口选择套餐。
4. 使用余额或可用支付方式完成购买。
5. 回到 `Usage Logs` 和 `Wallet` 查看消耗与余额变化。
