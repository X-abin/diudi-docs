# 充值余额

余额充值用于给 DouDi.ai 账户增加可消费额度。公开前端文案显示，充值成功后额度会进入钱包；支付可能以人民币结算，页面会展示实际支付金额、到账额度、订单号、支付方式和充值前后余额。

## 充值步骤

1. 登录 [https://doudi.ai](https://doudi.ai)。
2. 进入控制台中的 `Wallet`。
3. 查看当前余额和充值入口。
4. 选择或输入充值金额。
5. 选择支付方式。
6. 确认支付金额和到账额度。
7. 支付完成后回到 `Wallet` 查看余额是否更新。

## 页面中可能看到的字段

| 字段 | 说明 |
| --- | --- |
| Balance | 当前余额。 |
| Wallet credit | 充值额度。 |
| Amount to pay | 待支付金额。 |
| Actual payment | 实际支付金额。 |
| Credited Quota | 到账额度。 |
| Balance Before | 充值前余额。 |
| Balance After | 充值后余额。 |
| Order Number | 订单号。 |
| Payment Request IP | 付款请求 IP。 |

## 支付方式

前端配置中出现了支付宝、微信、Stripe、USDT 网络和自定义支付方式等能力。你实际能看到哪些支付方式，取决于 DouDi.ai 当前后台配置。

如果页面提示“尚未启用在线充值”，可以使用兑换码或联系管理员。

## 折扣与最低充值

站点前端包含金额折扣、最低充值金额和优惠提示相关文案，例如：

- 充值金额可能有最低要求。
- 不同充值金额可能对应不同折扣。
- 页面可能显示节省金额或折扣百分比。

充值前请重点核对两件事：

1. 实际支付金额。
2. 支付成功后到账额度。

## 充值后如何确认到账

1. 查看 `Wallet` 当前余额是否增加。
2. 查看钱包流水中是否出现新记录。
3. 查看订单状态是否为成功或可用。
4. 如果余额没有变化，保留订单号和支付截图后联系平台处理。

::: tip
给生产项目充值前，建议先用小额充值验证支付链路和到账逻辑。
:::
