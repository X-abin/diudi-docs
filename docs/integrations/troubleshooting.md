# 常见问题排查

如果接入工具失败，建议先按这一页从上到下排查。大多数问题都来自 Base URL、API Key、模型权限或客户端自动拼接路径。

## 快速自检

| 检查项 | 正确状态 |
| --- | --- |
| Base URL | `https://doudi.ai/v1` |
| API Key | 控制台创建，未禁用，复制完整 |
| 模型名 | 当前账号可用模型 |
| 余额 | `Wallet` 中额度充足 |
| 日志 | `Usage Logs` 中能看到请求记录 |

## 401 Unauthorized

常见原因：

- API Key 没填。
- API Key 复制不完整。
- Key 已被禁用或删除。
- 客户端要求只填 Key，但你填了 `Bearer xxx`。

处理方式：

1. 到 DouDi.ai 控制台重新复制或新建 API Key。
2. 确认客户端保存成功。
3. 用 curl 直接请求验证 Key 是否有效。

## 403 Forbidden

常见原因：

- 当前账号没有模型或分组权限。
- 使用了不兼容的供应商协议。
- 代理层改写了 Header 或路径。
- 工具固定请求了不支持的接口。

处理方式：

1. 换用控制台明确可用的模型。
2. 检查是否使用 OpenAI Compatible 模式。
3. 查看 DouDi.ai `Usage Logs` 和代理日志。
4. 如果直连成功但客户端失败，再考虑代理层。

## 404 Not Found

常见原因：

- Base URL 写错。
- 客户端自动拼接了 `/v1`，你又手动写了一次。
- 把完整接口地址填到了只需要 Base URL 的地方。

处理方式：

- 如果工具要求 Base URL，填写 `https://doudi.ai/v1`。
- 如果工具会自动加 `/v1`，尝试填写 `https://doudi.ai`。
- 如果工具要求完整 URL，填写 `https://doudi.ai/v1/chat/completions`。

## 模型列表为空

这不一定代表不能使用。部分客户端不会读取 DouDi.ai 的模型列表，或读取模型列表的接口不兼容。

处理方式：

- 手动添加模型名。
- 到[模型与价格](/guide/models-pricing)页面复制模型名。
- 登录 DouDi.ai 控制台查看自己账号实际可用模型。

## 余额不足或消耗异常

处理方式：

1. 到 `Wallet` 查看余额。
2. 到 `Usage Logs` 查看是哪一个模型和 API Key 产生消耗。
3. 给测试 Key 设置较低额度。
4. 减少上下文长度和最大输出长度。

## 请求很慢或超时

可能原因：

- 选择了高推理或长上下文模型。
- 输入上下文太长。
- 客户端网络到 DouDi.ai 不稳定。
- 工具重试次数太少或超时时间太短。

处理方式：

- 先用短问题测试连通性。
- 换用轻量模型。
- 降低上下文长度。
- 适当增加客户端超时时间。
