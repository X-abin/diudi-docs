# Cursor

Cursor 可以通过 OpenAI Compatible 方式接入 DouDi.ai。适合代码补全、代码解释、重构和代理式编程任务。

## 配置步骤

1. 打开 Cursor 设置。
2. 找到模型或 API Provider 相关配置。
3. 选择 OpenAI Compatible 或自定义 OpenAI 服务商。
4. 填写 Base URL：`https://doudi.ai/v1`。
5. 填写 DouDi.ai 控制台创建的 API Key。
6. 填写或选择模型，例如 `gpt-5.6`、`gpt-5.5` 或你的账号可用模型。
7. 保存后发送一条测试消息。

## 推荐检查

| 问题 | 处理 |
| --- | --- |
| 模型列表为空 | 手动输入模型名，或确认账号是否有模型权限。 |
| 请求 401 | 检查 API Key 是否复制完整，Key 是否被禁用。 |
| 请求 404 | 检查 Base URL 是否为 `https://doudi.ai/v1`。 |
| 生成很慢 | 尝试低倍率或轻量模型，并降低上下文长度。 |

## 使用建议

- 代码代理任务更容易消耗额度，建议先用测试 Key 设置较低额度。
- 处理大型项目时，减少无关文件上下文可以降低消耗。
- 如果使用长上下文模型，先在 DouDi.ai 控制台确认该模型对当前账号可用。
