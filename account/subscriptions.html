订阅套餐选择 ​

订阅套餐用于获得一段时间内的权益或额度。公开前端文案中出现了“我的订阅”“选择订阅套餐”“每月 token”“余额购买订阅”“余额购买订阅优惠码”等能力。

购买流程 ​

  1. 登录 DouDi.ai。
  2. 进入 My Subscriptions 或订阅相关入口。
  3. 查看可购买套餐。
  4. 对比套餐价格、有效期、每月 token、权益和限制。
  5. 选择适合自己的套餐。
  6. 使用余额或可用支付方式完成购买。
  7. 购买后回到 My Subscriptions 查看订阅是否生效。

如何选择套餐 ​

使用场景选择建议
只是测试 API先小额充值，不急着购买高阶订阅。
偶尔使用聊天或轻量代码任务选择低门槛套餐，关注每月 token 和可用模型。
经常用 Cursor、Codex CLI、Claude Code优先关注高频代码任务的额度、模型权限和稳定性。
团队或生产项目关注额度上限、可用模型、调用日志、发票和续费方式。
不确定用量先用钱包余额跑几天，依据 Usage Logs 再选择套餐。

购买前需要核对 ​

  • 套餐是否支持你需要的模型。
  • 套餐是否有每月 token 或额度限制。
  • 套餐是否有有效期和自动重置规则。
  • 是否支持优惠码。
  • 是否能使用余额购买。
  • 购买后是否支持退款或变更。
  • 发票选项是否符合你的报销要求。

余额购买订阅 ​

公开前端文案显示，站点支持“余额购买订阅”。如果该功能对你的账号开放，推荐流程是：

  1. 先在 Wallet 充值余额。
  2. 到订阅页面选择套餐。
  3. 在支付确认页选择余额支付。
  4. 如有优惠码，确认优惠码是否适用于余额购买订阅。
  5. 完成购买后查看余额扣减和订阅状态。

订阅记录 ​

购买后可以在“我的订阅”中查看订阅记录。如果页面显示“暂无订阅记录”或“暂无订阅套餐”，说明当前账号暂无记录，或平台暂未开放可购买套餐。

WARNING

具体套餐名称、价格、可用模型和每月 token 以登录后页面实时显示为准。公开页面无法直接读取当前可售套餐列表。
